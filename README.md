# Your Pizzeria

Webová aplikace (Single Page App) pro moderní pizzerii (vzorová šablona) vytvořená v Reactu, TypeScriptu, Tailwind CSS a Lucide React.

## Lokální spuštění

1. Nainstalujte závislosti:
   ```bash
   npm install
   ```
2. Spusťte vývojový server:
   ```bash
   npm run dev
   ```
3. Produkční sestavení:
   ```bash
   npm run build
   ```
